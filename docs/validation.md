## 已实现与自动测试

- 在单视频和批次入口接入抖音标准视频 URL，保留平台、ID、时间戳和原始证据。
- 接入官方 b23.tv / v.douyin.com 分享短链解析；仅请求对应固定短链域名，
  检查跳转协议、主机、账号信息与视频路径，不访问其他跳转目标。
- 批次 dry-run 不联网、不解析短链；相同短链去重，但短链与标准链接不会提前视作重复。
- 抖音 worker 仅启用对应的 yt-dlp extractor，过滤平台元数据和原始响应；
  请求 ID 与响应 ID 不一致时拒绝。B站原有隔离、预算、权限和失败保护保留。
- 模拟抖音下载、批量混合与输出来源；测试超长/恶意 URL、跨平台/内网重定向、
  无 Key 阻止付费下载、平台异常不泄露原始日志；模拟测试不代表实际媒体下载已成功。
- 实际 SDK 报告需要 Cookie 时，只返回类别化提示，不输出原始错误或鉴权信息。
- Python 核心、CLI 和 Skill 同步更新，独立核心不依赖 Codex。没有真实付费请求。
