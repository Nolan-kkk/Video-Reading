# VideoMind Skill 问题与改进清单

记录日期：2026-11-04  
适用版本：0.2.1

本文区分已经发现的问题、能力限制与尚未完成的真实验收，供后续开发和发布时逐项核对。项目范围为本地视频、B 站和抖音；不再规划 YouTube 接入。

更新：用户已选择 Apache-2.0 许可证；下面涉及“暂不决定”的描述保留当时记录。

## 优先级 P0：核心使用受阻或尚未真实跑通

### 1. 抖音视频真实获取尚未跑通

- **现状**：已支持标准视频链接、官方分享短链解析，并完成模拟下载和批量处理测试。
- **实际结果**：用户提供的分享短链可以解析，但匿名获取视频元数据时平台要求额外验证；其他公开样例也出现同类限制。尚无抖音媒体下载成功后的端到端验收。
- **影响**：不能保证抖音链接可直接处理，也不能声称已完成抖音音频、画面识别验收。
- **临时方案**：处理用户有权提供的本地视频文件。
- **后续方向**：研究符合平台规则的获取方案，明确访问限制和错误提示；完成真实媒体下载、语音、OCR 和批量处理的端到端验收。不读取用户浏览器 Cookie，也不绕过平台访问控制。

### 2. DeepSeek 图像和文本理解尚未真实验收

- **现状**：已实现用户自备 Key 的 DeepSeek 适配器，并通过离线契约与模拟响应测试。
- **影响**：真实接口可用性、账单和关键帧语义理解效果尚未验证；不能把模拟测试等同于真实识别成功。
- **后续方向**：在用户明确授权费用后，使用用户自己配置的 Key，对可控样例验证请求、输出质量、实际用量和错误处理。不要在聊天、命令行参数或仓库中暴露 Key。

## 优先级 P1：识别质量与结果能力

### 3. 本地语音识别存在错误

- **现状**：可使用本地 faster-whisper 将视频语音转为带时间戳的文字，不需要 API Key。真实 B 站样例已验证，但出现过同音字错误。
- **影响**：专有名词、背景噪声、多说话人等场景可能降低准确率；不能将自动转录原文视为完全准确。
- **后续方向**：增加不同音质和内容的样例评估，研究模型选择及质量提示；原始字幕、ASR 和 OCR 应分别保留，不静默修改识别原文。

### 4. 本地画面识别主要限于 OCR

- **现状**：可提取视频关键帧并用 OCR 识别画面文字，保留时间、置信度和位置。
- **影响**：本地 OCR 不理解图表含义、画面事件或 PPT 语义，也不还原代码结构；抽帧受间隔和数量限制，可能遗漏短暂画面。
- **后续方向**：优化关键帧覆盖和 OCR 质量；对 PPT、代码和视觉内容进行真实样例评估，并清楚标记未识别或不确定内容。云端语义理解的真实验收见问题 2。

### 5. 多视频融合总结的验证

不要求单独的 DeepSeek Key；跨视频真实样例仍待验收。以下为此前的问题记录。

- **现状**：批量处理支持去重、并发、失败隔离和校验续跑；`batch_summary.md` 是各视频证据的索引。
- **影响**：不能自动把多个视频归纳为一份跨视频 AI 分析报告。
- **后续方向**：设计有来源和时间戳引用的跨视频综合输出；任何云端处理均须使用用户自己的 Key，并预先说明费用与发送内容。

## 优先级 P2：易用性、稳定性和维护

### 6. 安装和使用门槛较高

- **现状**：主要通过命令行和 Codex Skill 使用；部分功能需要 FFmpeg、可选 Python 依赖以及本地语音模型。
- **影响**：首次配置对非技术用户较复杂；下载模型需要网络和磁盘空间。
- **后续方向**：改进安装文档、依赖诊断与错误提示，逐步简化首次运行流程。

### 7. 批量任务仍有操作限制

- **现状**：同一批次可校验续跑，但没有跨批次缓存和自动错误退避；短链与同一视频的标准链接在离线预览时不会识别为重复。
- **影响**：重复运行可能重复计算；需要人工处理失败或等待平台恢复。涉及付费请求时重复运行可能再次计费。
- **后续方向**：设计安全的跨批次缓存和针对可重试错误的退避；保留付费请求预算和未知计费结果的保护，不自动重发可能已收费的请求。

### 8. 云端价格快照需要维护

- **现状**：当前 DeepSeek 价格快照核对日期为 2026-11-04，有效至 2026-11-11；过期后付费调用会被阻止。
- **影响**：需要维护者核对价格并更新快照后才能继续调用；预算限制针对当前运行，不是服务商账户的全局限额。
- **后续方向**：建立价格核对与更新流程，保持费用预估、有效期和失败提示清晰。

### 9. 平台及运行环境验证仍不完整

- **现状**：本地 Windows 测试通过；Windows/Linux GitHub Actions 配置已准备，但尚未在 GitHub 执行，也没有 Linux 实机验收。
- **影响**：不能将本地测试或类型检查视为所有系统和真实平台接口均已验证。
- **后续方向**：在实际 GitHub 仓库运行 CI，并补充 Linux 安装、媒体处理和离线测试记录；持续记录 B 站与抖音真实样例的结果。

### 10. 开源发布尚未完成

- **现状**：尚未发布到 GitHub；用户明确选择暂不决定许可证。
- **影响**：目前不能将许可证或正式开源发布视为已完成。
- **后续方向**：在许可证确定之前继续完善代码、文档和测试；不要擅自选择许可证。发布前检查隐私数据、依赖和发布产物。

## 已有验证与边界

- 本地语音识别、OCR 和 B 站真实样例已完成验证；混合批次中 B 站项成功，抖音项受平台访问限制而失败，且未拖累其他任务。
- 最新完整离线回归为 **213 项通过，无跳过**；不代表真实云端 API 或抖音媒体链路已验收。
